## Decisions

- **CRLF in `docs/tasks/`:** `docs/tasks/PRD.MD` and `docs/tasks/prompt.md` had CRLF endings. I converted them to LF before the baseline commit so the working tree matches the index. Only the line endings changed.
- **AGENTS.md formatting:** `AGENTS.md` had no trailing newline, so the appended heading had no blank line above it. I fixed this and amended the unpushed P0 commit.
- **`next-env.d.ts`:** it stays git-ignored, as in the original create-next-app `.gitignore`. It is generated by `next dev` and `next build`.
- **`tsconfig.tsbuildinfo`:** it stays on disk but untracked, because `*.tsbuildinfo` is ignored.
- **Untouched paths:** nothing under `app/`, `components/`, `data/` or `public/` was modified. No packages were installed or upgraded.
